# CYQORA - Cyber Risk Quantification & Investment Optimization

This repository contains the CYQORA web application and backend.

View your app in AI Studio: https://ai.studio/apps/e2f8167c-f177-4d85-8177-d3d44ddd5134

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in `.env` (or `.env.local`) to your Gemini API key
3. Run the app:
   `npm run dev`
